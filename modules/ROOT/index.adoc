= Model Context Protocol (MCP) for Ansible Automation Platform

== Welcome to the MCP Course

This course will teach you everything you need to know about the **Model Context Protocol (MCP)** and how to use it with **Ansible Automation Platform (AAP)**.

Whether you're an automation engineer, a cloud architect, or a developer looking to integrate AI with your Ansible workflows, this course is designed to give you the practical knowledge to deploy and use MCP in real-world scenarios.

=== What You'll Learn

By the end of this course, you will:

* **Understand what MCP is** — the open standard that connects AI tools to your infrastructure
* **Grasp the architecture** — how different components work together
* **Deploy MCP** — get it running on OpenShift Container Platform (OCP)
* **Integrate with AAP** — connect your favorite AI tools to Ansible Automation Platform
* **Query and interact** — use natural language to ask questions and run automation tasks
* **Troubleshoot** — solve common issues and understand the workflow

=== Course Structure

This course has **2 main chapters** and practical hands-on labs:

[cols="1,3"]
|===
| **Chapter 1: MCP & AAP Integration** | Learn what MCP is, why it matters, and how AAP extends it. See the complete workflow from user to AI tool to AAP.
| **Chapter 2: Hands-On Labs** | Deploy MCP on OCP, connect your tools (Claude, Cursor, LibreChat), and run real queries against your AAP instance.
|===

=== Who This Course Is For

You have **basic knowledge of:**

* Linux and containers
* OpenShift Container Platform (OCP)
* Ansible Automation Platform (AAP) basics
* APIs and REST concepts

You **do not need:**

* Deep MCP expertise
* AI/LLM knowledge (we explain as we go)
* Experience with specific AI tools

=== How to Use This Course

This is designed as an **instructor-led course**, but you can also self-study.

For each concept, we follow this pattern:

1. **What is it?** — Simple explanation without jargon
2. **Why is it needed?** — Real-world problem it solves
3. **How does it work?** — Architecture and flow diagrams
4. **Try it yourself** — Hands-on labs with step-by-step commands

=== Time Required

* **Chapter 1** (Learning): 30-45 minutes
* **Chapter 2** (Labs): 60-90 minutes per lab
* **Total**: 2-3 hours for full course

Ready to dive in? Head to **Chapter 1** to understand what MCP is and why Ansible uses it.
