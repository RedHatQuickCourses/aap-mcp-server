= Model Context Protocol (MCP) for Ansible Automation Platform

Welcome to the learning section of this course. In this chapter, you will understand what the Model Context Protocol is, how it works, and how Ansible Automation Platform uses it to connect with AI tools.

We'll break this down into bite-sized sections that follow a simple pattern: **What is it? → Why is it needed? → How does it work?**

== What You'll Learn

By the end of this chapter, you will be able to:

* Define the Model Context Protocol and understand its role in the AI ecosystem
* Understand the architecture of MCP and how different components interact
* Explain Ansible Automation Platform's MCP server and its capabilities
* Describe the complete communication workflow from user to AI to AAP
* Identify and describe the 6 AAP MCP toolsets
* Understand the end-to-end workflow for deploying and using MCP

== Dev Spaces Workspace

=== Launching a specific Dev Spaces Workspace

Once you have launched the OpenShift Dev Spaces console, use the following steps to access your Ansible Dev Space workspace.

. Login via OpenShift authentication using the same credentials as the OpenShift console
. Select **Allow selected permissions** to authorize access and launch the console
. Scroll down and select the workspace sample titled **Ansible Dev Space**
+
image::intro3.png[link=self,window=blank]
+
NOTE: It will take a few minutes for the Dev Spaces instance to initialize. When it has loaded, a Visual Studio Code interface will appear.
+
image::intro4.png[link=self,window=blank]
+

. Click the **Yes, I trust the Authors** button to trust the workspace authors (your instructors).
