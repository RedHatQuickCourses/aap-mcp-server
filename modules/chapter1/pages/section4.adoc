= Know More About MCP Tool Discovery and Access Control

== Optimize Token Usage with the Discover Endpoint

When integrating an AI agent with an MCP server, loading every tool for each request can increase token consumption. The discover endpoint helps optimize this by providing a lightweight summary of available toolsets.

The AI agent identifies the relevant toolset and loads only the tools required for the task.

[source,text]
----
<MCP server URL>/mcp/discover
----

Once loaded, tools remain available for the rest of the session. Additional toolsets are loaded as needed.

== Access All Tools

If token optimization is not a priority, use the all-tools endpoint to make every tool available.

[source,text]
----
<MCP server URL>/mcp
----

== Restrict Access to Specific Toolsets

To control which tools the AI agent can access, configure a separate endpoint for each toolset.

[source,text]
----
<MCP server URL>/mcp/<toolset>
----

Available toolsets:
`job_management`, `inventory_management`, `system_monitoring`,
`user_management`, `security_compliance`, `platform_configuration`,
`content_discovery`.

== Understand Server-Level and User-Level Permissions

The MCP server uses two layers of access control:

* **Server-level permissions:** Configured by the administrator during deployment.
** Read-only: Allows the AI agent to retrieve information without making changes.
** Read-write: Allows changes, subject to the user's API token permissions.

* **User-level permissions:** Inherited from the user's Ansible Automation Platform API token. The AI agent can perform only actions authorized for that user.

For example, if a user can access the `network` inventory but not the `database` inventory, the AI agent cannot access the database inventory using that user's token.

== Security Consideration

Read-write access allows the AI agent to make changes in Ansible Automation Platform, including launching automation jobs when authorized.

Because AI agents may misinterpret requests, start with read-only access and introduce write permissions only when appropriate safeguards and RBAC controls are in place.
